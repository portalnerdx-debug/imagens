# Agente Local XVendas Click (visual)

1. Instale Node.js LTS.
2. Abra a pasta `apps/local-agent`.
3. Copie `.env.example` para `.env` e preencha usuário/senha da Click.
4. Dê duplo clique em `INICIAR-AGENTE.bat`.
5. Deixe a janela preta aberta.
6. Abra o XVendas e faça a consulta.

O agente abre um Chromium visível e reutiliza os mesmos módulos Playwright do robô. Ao final, a janela permanece aberta no orçamento final.
