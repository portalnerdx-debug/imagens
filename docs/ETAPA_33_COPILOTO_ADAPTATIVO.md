# Etapa 33 — Copiloto Adaptativo

Implementado:
- aprendizado histórico conectado à Próxima Melhor Ação;
- combos históricos usados na Venda Combinada;
- abordagens com melhor conversão usadas como orientação;
- filtro por estoque disponível;
- peso menor para amostras pequenas;
- proteção para não sugerir adicionais quando o cliente já está em momento forte de fechamento;
- necessidade e orçamento continuam tendo prioridade.
