# Etapa 07 — Venda Combinada

Implementado:
- Venda Combinada Inteligente;
- Venda Cruzada em Cadeia;
- Montador de Casa Completa — primeira versão;
- controle de orçamento;
- seleção de complementos;
- alerta quando os complementos ultrapassam o orçamento;
- API inicial de sugestões por categoria.

## Valores
Os valores exibidos nesta etapa são demonstrativos. Eles não devem ser tratados como preços reais da loja.

Quando a integração de preços e estoque estiver pronta, as sugestões usarão preço e disponibilidade atuais.

## Princípio
O sistema não recomenda adicionais apenas para aumentar a venda. A sugestão deve ter relação com a necessidade registrada e respeitar o orçamento informado.
