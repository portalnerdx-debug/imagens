# Etapa 30 — Comparação compartilhável para o cliente

Implementado:
- seleção de até 3 produtos pesquisados;
- comparação simples com nome, código, preço e disponibilidade capturada;
- geração de link contendo a seleção;
- botão para copiar o link;
- representação visual de QR para preparar a interface;
- aviso explícito para reconfirmar preço e estoque.

## Importante
O desenho de código desta etapa é demonstrativo e não deve ser tratado como QR Code escaneável. Para produção será usada uma biblioteca de QR Code real e uma rota pública dedicada.

## Próxima etapa
Criar rota pública real de comparação + QR Code escaneável + expiração/atualização segura dos dados compartilhados.
