# Etapa 04 — Ficha Inteligente do Produto

Adicionado:
- ficha por código;
- características;
- transformação visual Característica → Benefício;
- público indicado;
- argumentos de venda;
- roteiro de demonstração física;
- cadastro manual inicial;
- dois produtos demonstrativos para testar a interface;
- endpoints básicos para futura persistência.

A ficha não inventa especificações do produto pesquisado na Plataforma Click. Enquanto não houver integração com uma fonte confiável de características, o vendedor cadastra os dados ou usa fichas previamente validadas.
