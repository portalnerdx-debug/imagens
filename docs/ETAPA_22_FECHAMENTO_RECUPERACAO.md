# Etapa 22 — Momento de Fechamento + Chance + Salvar Venda

Implementado:
- Detector de Momento de Fechamento;
- Chance de Fechamento de 0 a 100;
- classificação fria/morna/quente;
- sinais como parcela, entrega, estoque, garantia e intenção explícita;
- detecção de riscos/objeções;
- Próxima Melhor Ação;
- módulo “Cliente disse...”;
- estratégias para preço, parcela, “vou pensar”, decisão com familiar e concorrência.

A chance é heurística. Ela serve para orientar o vendedor e não representa probabilidade estatística garantida.
