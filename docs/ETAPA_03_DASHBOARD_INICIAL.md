# Etapa 3 — Dashboard inicial do vendedor

A abertura do XVendas foi transformada em um painel de ações rápidas.

## Atalhos
- Novo atendimento
- Pesquisar produto
- Simular crediário
- Treinar vendas
- Minhas metas
- Histórico de atendimentos

## Comportamento
O atendimento guiado continua usando as seis etapas existentes. Consultas rápidas podem ser abertas sem criar um atendimento. O histórico usa os atendimentos já persistidos no Firestore e exibe os registros mais recentes.
