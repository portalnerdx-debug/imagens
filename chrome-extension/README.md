# Extensão XVendas Click

1. Abra `chrome://extensions` no Chrome/Edge.
2. Ative **Modo do desenvolvedor**.
3. Clique em **Carregar sem compactação** e selecione a pasta `chrome-extension`.
4. Faça login normalmente na Plataforma Click.
5. No XVendas, clique em Consultar. A extensão abre uma aba real da Click e executa as ações visivelmente.

A extensão usa os dados enviados pelo XVendas e a sessão já autenticada no navegador do usuário.
